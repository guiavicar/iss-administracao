# ISS Administração

Site institucional da ISS Administração — soluções completas em administração para condomínios, empresas e pequenos negócios.

Site estático (HTML/CSS/JS), publicado via GitHub Pages.

- `index.html` — página única
- `styles.css` — identidade visual (navy + dourado, extraída da logo)
- `script.js` — menu, animações e formulário que envia para o WhatsApp
- `assets/logo.jpg` — logo da marca (quadrada, usada nos círculos)
- `assets/logo-og.jpg` — logo em alta para compartilhamento (og:image)
- `assets/img/` — fotos (equipe, CEO, carro, condomínios, revista e eventos)
